# Agenda Personal

Aplicación de agenda personal con calendario, registro de usuarios y gestión de citas.

## Funcionalidades

- Login y registro de usuarios
- Calendario interactivo
- Crear, editar y eliminar citas
- Citas de un solo día o de varios días
- Control de estado (pendiente/terminada)

## Tecnologías

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP + PDO
- **Base de datos**: MySQL (XAMPP) / PostgreSQL (Supabase)

## Archivos

- `index.php` - Página de login
- `registro.php` - Registro de usuarios
- `agenda.php` - Panel principal con calendario
- `conexion.php` - Conexión a la base de datos
- `styles.css` - Estilos
- `schema_supabase.sql` - Schema para migrar a Supabase
